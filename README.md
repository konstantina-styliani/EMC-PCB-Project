# EMC-PCB-Project in HFSS
Course: Electromagnetic Compatibility


Investigated the electromagnetic compatibility (EMC) of a PCB and techniques for ensuring EMC performance without necessarily relying on shielding.The study examined the effect of operating frequency range, conductive trace geometry, and passive component placement on parasitic electromagnetic phenomena. PCB layouts were modeled and parametric simulations were performed in HFSS to determine the optimal spacing and relative orientation between two conductive traces, targeting minimum electromagnetic interference (EMI).

## Note

The .aedt files require ANSYS Electronics Desktop (HFSS) to be installed
in order to be opened and edited.
